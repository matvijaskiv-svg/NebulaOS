# NebulaOS

Дистрибутив на базе Arch Linux в стиле macOS с **тремя режимами работы**. У каждого
режима свой дизайн и свои функции, переключение на лету: `Super+M`, клик правой
кнопкой по логотипу или Nebula Hub (`Super+H`). Фирменный стиль описан в [DESIGN.md](DESIGN.md).

| Режим | Стиль | Функции |
|---|---|---|
| **Гейминг** (по умолчанию) | неон, в духе Garuda dr460nized | турбо-режим `Super+G`, MangoHud для всех игр, ядро linux-zen, Steam, Lutris, Wine |
| **Хакинг** | Catppuccin Mocha, в духе Garuda Mokka | IP на панели, Tor, случайный MAC, Wireshark, nmap, Ghidra и др. (для своих стендов) |
| **Сервер** | цвета Ubuntu, док слева | нагрузка/диск на панели, включение SSH/Docker/Cockpit/nginx/PostgreSQL с файрволом |

## Язык

Языки: **English, Русский, Українська, Italiano**. Язык выбирается в мастере первого запуска,
в Nebula Hub (Appearance → Language) или командой `nebula lang ru`, а также при установке.
Раскладка следует за языком (`Alt+Shift` переключает). Переводы — в `tools/translations.py`
(после правки: `python tools/translations.py`). Тестирование и известные проблемы — в [TESTING.md](TESTING.md).

## Возможности

- **Nebula Center** (`Super+C`, клик по часам): Wi-Fi, Bluetooth, «Не беспокоить», ночной свет, громкость,
  яркость, профиль питания, режимы, плеер, календарь, загрузка системы, погода.
- **Мастер первого запуска**, **Nebula Store** (`Super+Shift+A`, Arch + Flathub), **автосмена режима** по программам,
  **графический установщик**, анимированные обои, резервные копии, поиск файлов (`Super+Shift+F`),
  `fix` и `… | ai` для разбора ошибок в терминале.
- **Хакинг:** учебные стенды DVWA / Juice Shop / WebGoat (только 127.0.0.1), приватный браузер, индикатор VPN/Tor.
- **Сервер:** готовые серверы в Docker — файлообменник, Jellyfin, Minecraft.

- **Стиль macOS:** стеклянная панель сверху, док, поиск приложений (`Super+Space`), уведомления,
  кнопки окон слева «светофором». Окна программ (GTK, libadwaita, Firefox, Qt) — в цветах режима.
- **Свой дизайн:** логотип «Орбита», иконки Papirus, курсор Capitaine, темы GRUB, Plymouth и экрана входа SDDM.
- **Замок оформления:** пользователь меняет только обои и положение дока (`nebula settings` или Hub).
- **Nebula Hub** (`Super+H`): режимы, оформление, обновления, драйверы, снимки, функции режимов, ассистент, установка.
- **Обновления NebulaOS:** всё оформление — пакет `nebulaos-desktop` в собственном репозитории.
  `nebula update` (или значок на панели) обновляет и NebulaOS, и Arch, показывает «что нового».
- **Снимки и откат:** Btrfs + Snapper, снимок до и после каждого обновления, откат из меню GRUB.
- **Установщик** с **дуал-бутом**: на весь диск или рядом с Windows (в свободное место, Windows в меню GRUB).
- **Драйверы:** `nebula drivers` подбирает пакеты для NVIDIA, AMD и Intel.
- **AI-ассистент** (`Super+A`): окно поверх экрана, локальная модель Ollama, данные не уходят в сеть.
- **Мелочи:** история буфера (`Super+V`), ночной свет (`Super+Shift+N`), запись экрана
  (`Super+Shift+R`), скриншот области (`Super+Shift+S`), выезжающий терминал (`` Super+` ``),
  zram и настройки ядра для отзывчивости.

### Горячие клавиши (Super = ⌘)

`Super+Space` — поиск · `Super+Enter` — терминал · `Super+Q` — закрыть · `Super+M` — режим ·
`Super+H` — Hub · `Super+A` — ассистент · `Super+L` — блокировка · `Super+1…5` — рабочие столы ·
`Super+Ctrl+R` — перезапустить панель · `Alt+Shift` — раскладка us/ru.

## Как собрать ISO

`mkarchiso` работает только в Arch Linux. На Windows проще всего через WSL.

1. Один раз установите Arch в WSL (PowerShell):
   ```powershell
   wsl --install archlinux
   ```
2. Соберите (20–40 минут, скачает ~2 ГБ):
   ```powershell
   wsl -d archlinux -u root
   ```
   ```sh
   pacman -Syu --noconfirm --needed archiso grub base-devel
   rm -rf ~/nebulaos && cp -r /mnt/c/Users/matvi/Desktop/nebulaos ~/nebulaos
   cd ~/nebulaos && bash build.sh
   cp out/*.iso /mnt/c/Users/matvi/Desktop/
   ```

Другие варианты: Docker (`docker run --rm --privileged -v "${PWD}:/nebulaos" archlinux:latest bash -c "pacman -Syu --noconfirm archiso grub base-devel && bash /nebulaos/build.sh"`)
или ВМ с Arch (`sudo bash build.sh`). `bash build.sh --prepare` — всё, кроме долгой сборки.

`build.sh` собирает пакет `nebulaos-desktop` в локальный репозиторий, накладывает профиль на
официальный `releng`, отключает конфликтующие службы (networkd, iwd, sshd, автовход root),
брендирует загрузку и проверяет, что **все** пакеты есть в репозиториях.

## Как выпускать обновления NebulaOS

Всё идёт через GitHub `matvijaskiv-svg/NebulaOS`, своего сервера нет.

- **Пакеты.** Pacman в каждой NebulaOS читает репозиторий `[nebulaos]` из GitHub-релиза `repo`
  (`https://github.com/matvijaskiv-svg/NebulaOS/releases/download/repo`, адрес по умолчанию в `build.sh`).
- **Новости и проверка версии.** Файл `channel/channel.json` в ветке `main`: новости, последняя версия,
  адрес поддержки. Таймер `nebula-update-check` (через 3 минуты после входа и затем каждые 6 часов)
  показывает уведомления о новостях, о новой версии и о наличии обновлений.
- **Установка обновления.** Пользователь запускает `nebula update` или кнопку в Настройках: снимок Btrfs, затем `pacman -Syu`.
  Без спроса система ничего не ставит, только уведомляет.

Выпуск обновления, одной командой на Arch/NebulaOS (нужен `gh auth login` один раз):

    bash tools/release.sh 0.6.1 "Что нового одной строкой"

Скрипт поднимает версию, собирает пакет, загружает его в релиз `repo`, добавляет новость и делает `git push`.
То же самое делает кнопка «Опубликовать обновление» в админке (`nebula admin`).

**Важно:** пока релиз `repo` не создан (первый запуск `tools/release.sh`), `nebula update` у пользователей
выдаёт ошибку загрузки базы `nebulaos`. Опубликуйте первый релиз до раздачи ISO.
Рекомендуется подписывать пакеты ключом GPG (`GPGKEY=...`) и затем поднять `SigLevel` до `Required`.
ISO (3,7 ГБ) нельзя положить в GitHub Releases целиком (лимит 2 ГБ на файл): раздавайте его через облако
или разрежьте (`split -b 1900M`).

## Nebula Chat

`nebula-chat` — мессенджер и лента без сервера (протокол Tox: P2P, сквозное шифрование).
- Личные чаты: фото, файлы до 8 МБ, «печатает…», галочки «доставлено/прочитано».
- Профиль: аватар, имя, статус.
- Группы: владелец, модераторы, заглушка (только чтение), кик, закреплённое сообщение, вход по коду или приглашению.
- Лента (как в Instagram): посты с фото и лайками. Видят ваши контакты, пока они в сети: общей ленты без сервера не бывает.
- Официальные группы и опросы приходят из подписанного канала, пользователи входят в группы автоматически.
- Кнопка «Написать в поддержку NebulaOS».

Запросы в контакты принимаются только из Nebula Chat. Это фильтр, а не защита: протокол Tox открытый.
Сообщения ходят, пока программа запущена у обоих. Она стартует со входом и ждёт в трее, а неотправленное уходит само.

## Админка — только у вас

Админки **нет в ISO**: она лежит в `tools/admin/` и ставится только на ваш компьютер:

    sudo install -m755 tools/admin/nebula-admin /usr/local/bin/

Всё, что видят пользователи, хранится в `channel/channel.json` и подписано вашим ключом Ed25519 (`channel/channel.sig`).
Это новости, опросы, официальные группы, бан-лист, обои недели, адрес поддержки и придержанные версии.
Каждая NebulaOS проверяет подпись по `/usr/share/nebulaos/admin.pub` и молча игнорирует всё неподписанное.
Копия админки без ключа бесполезна.

- **Секретный ключ:** `C:\Users\matvi\NebulaOS-admin-key\admin.key`. Он вне репозитория, никогда не публикуйте его.
  Сделайте резервную копию (флешка, менеджер паролей). Без ключа новые новости опубликовать нельзя:
  придётся выпускать новый ключ, а с ним и новый ISO.
- **Перенос ключа в вашу NebulaOS:** Админка → «Ключи» → «Импортировать admin.key», он ляжет в `~/.config/nebulaos/admin.key`.
- **Подпись канала вручную:** `python3 tools/admin/sign-channel.py`.

Разделы админки:
- **Обзор:** онлайн и всего пользователей, версии, режимы, языки, скачивания, звёзды и вопросы на GitHub.
- **Новости:** объявление с кнопкой («Обновиться», «Открыть чат», ссылка).
- **Опросы:** вопрос всем и результаты в реальном времени.
- **Сообщество:** официальные группы, закреп, бан-лист.
- **Поддержка:** ваш Nebula ID как адрес поддержки.
- **Обои недели:** у всех появятся с кнопкой «Установить».
- **Выпуск:** обновление, «придержать» сломанную версию, сборка ISO.
- **Ключи:** ключ подписи и копия репозитория.

Статистика и голоса приходят через официальную группу, поэтому держите свой Nebula Chat запущенным.
Пакеты pacman пока проверяются без GPG (`SigLevel = Optional TrustAll`). Подпись пакетов — следующий шаг
(`GPGKEY=... tools/publish-repo.sh` уже умеет).

## Проверка

Запускайте ISO сначала в виртуальной машине (UEFI и BIOS). В Live вход автоматический:
пользователь **nebula**, пароль **nebula**. Ошибки конфигурации Hyprland покажет `hyprctl configerrors`.
Перед дуал-бутом на реальном ПК сделайте резервную копию, отключите «Быстрый запуск» Windows
и сохраните ключ BitLocker.

## Структура

| Путь | Что это |
|---|---|
| `desktop/` | всё, что входит в пакет `nebulaos-desktop` (обновляется через репозиторий) |
| `desktop/usr/bin/nebula` | режимы, настройки, обновления, драйверы, Tor, сервер, снимки… |
| `desktop/usr/bin/nebula-hub`, `nebula-ai-overlay` | Nebula Hub и окно ассистента (GTK4 + libadwaita) |
| `desktop/usr/share/nebulaos/` | общие конфиги и режимы (`modes/<режим>/mode.env` — палитра) |
| `desktop/usr/share/{grub,plymouth,sddm}/themes/nebulaos` | темы загрузки и входа |
| `pkg/` | PKGBUILD пакета |
| `airootfs/` | только Live: пользователь, автологин, установщик `nebula-install` |
| `profiledef.sh`, `packages.x86_64`, `pacman.conf`, `build.sh` | профиль archiso и сборка |
| `tools/make-art.py`, `tools/publish-repo.sh` | графика и публикация репозитория |

## Безопасность

- Live: у root пустой пароль (как в releng), но автовход root и `sshd` выключены, `sudo` — по паролю.
- Установленная система: вход root заблокирован, пользователь в `wheel` с sudo по паролю,
  службы сервера включаются только явно, файрвол — `nebula server firewall`.
- Ollama слушает только `127.0.0.1`; ассистент не исполняет команды из ответов.
- Инструменты режима «Хакинг» — для своих стендов, CTF и тестов с разрешения владельца.
